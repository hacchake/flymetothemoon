# FLY ME TO THE MOON

**このハエを、月まで連れていけるか？**

夜の街を、1 匹のハエが飛ぶ。ハエの脳は、実在するショウジョウバエの全脳配線 **FlyWire** から抜き出した
約 3,800 個のニューロン。あなたにできるのは、ランタンを灯し、餌を置き、雲を浮かべることだけ。
どちらへ飛ぶかを決めるのは、ハエの神経回路だ。

人間には、ハエが月を目指しているように見える。
でも、このハエの中に「月」はない。あるのは光と、神経の発火と、翅の動きだけ。

## 遊ぶ

`index.html` をブラウザで開く（ダブルクリックでよい）。インストールも GPU も要らない。
音はブラウザの Web Audio で鳴る（最初のクリックで始まる）。

| 操作 | |
|---|---|
| **1 ランタン** | 押している間、光が灯る。ハエは近い光に引き寄せられる。電池に限りあり |
| **2 餌** | クリックで置く。匂いでハエを呼ぶ。食べると元気が戻る |
| **熟した果実** | クリックで置く。発酵した匂いが遠くまで届き、強く呼ぶ（ハエの Or42b がいちばんよく応える匂い） |
| **ドライアイス** | クリックで置く。二酸化炭素がたまり、ハエは失速して近づけない（ORN_V → 前進をつかさどる DNp09 が 71 → 29 Hz に落ちる） |
| **3 雲** | クリックで置く。光を遮り、行く手をふさぐ |
| **4 扇風機** | クリックで置く。上向きの風がハエを押し上げる |
| **5 鏡** | クリックで置く。月が見える場所なら、月の光を映して光る |
| 捕まったハエ | ハエトリ紙・クモの巣・酢のわなのハエを連打すると逃げ出す |
| 右クリック | 近くの餌・雲・罠を消す |
| カーソルを動かす | 音楽にキラキラした音が降る（左右 = 定位、上下 = 音の高さ） |
| `Space` / `R` / `B` / `M` / `V` | 一時停止 / やり直す / 脳の表示 / 音 / ハエの視線 |

12 のステージと、何でも置ける「自由実験」、自分でステージをつくれる「ステージをつくる」がある。
ハエは 3 匹。★ は「月に届く」「1 匹も失わない」「目標時間以内」。ハエが落ちるたびに、道具は最初の数まで補充される。

ハエを誘う光と匂い、そして罠：

- **街灯・車のヘッドライト**：近くの光は月より明るく見える。ハエは寄っていってしまう
- **殺虫灯**：紫外線は、人間には暗い青紫でも、ハエにはいちばんまぶしい光。触れると焼かれる
- **飛行機**：夜空を横切り、白いストロボが一瞬だけ強く光る
- **UFO**：色とりどりの光と、ときどき下ろすビーム。吸い込まれると、どこかへ降ろされる
- **ホタル**：点滅しながら漂う光の群れ
- **ハエトリ紙**：甘い匂いで誘う。**酢トラップ**：もっと強い匂いで誘い、落ちると沈む
- **クモの巣**：光も匂いもない。見えにくく、かかるとクモが近づいてくる
- **ハエ叩き・カエル**：迫る影を見ると、ハエの LPLC2 → Giant Fiber が発火して逃げる。逃げ遅れると…
- **魔女**：ごくまれに、月の前を横切る。会えたら特別なことが起きる

### ステージをつくる

タイトルの「ステージをつくる」で、スタート位置、月、罠を置き、高さ・道路・飛行機・曲・道具の数を決める。
「▶ 試す」ですぐ遊べ、「保存」でブラウザに残る。「共有 URL」はステージをまるごと URL に入れるので、
送った相手はその URL を開くだけで同じステージを遊べる（サーバは要らない）。

右側の 6 つの計器は、旋回・推力・方位・高さ・風・匂い（誘引と二酸化炭素）を出している。

画面の下は、ハエの脳そのもの。FlyWire の実際の立体座標に置いたニューロンを、ガウス分布の光の粒（スプラット）として WebGL で描いている。
ドラッグで回し、ホイールで近づき、ダブルクリックで正面に戻る。発火すると粒が明るくなり、光が実際のシナプスを伝って流れる。
左右の六角形は、ハエの複眼に映っている世界。

`tests.html` を開くと、行動が本当に神経回路から生まれているか（経路を切ると行動が崩れるか）を確かめられる。

## 脳のつくり

```
 光（月・街灯・殺虫灯…）   迫る影（ハエ叩き・車）   匂い（餌・酢・排気）   風と音（扇風機・ハエ叩き）
        │                        │                      │                        │
  LC10a/c/d・LC9・LC31a     LPLC2・LC4          ORN_DM1/DM2/DM4/VM2・ORN_V    JO-C/E・JO-B
        │                        │                      │                        │
        └──────── FlyWire v783 の実ニューロン 3,774 個・実シナプス 65 万 ───────────┘
                              │
                 DNa02（旋回）· DNp09（推力）· MDN · Giant Fiber（逃避）
                              │
                        翅 → 飛ぶ → 見えるものが変わる → …
```

- 視覚・逃避・嗅覚・触角の感覚まで、すべて **FlyWire v783 の実データ**（3,774 ニューロン、40,836 結合、約 65 万シナプス）。
  どの視覚ニューロンを入力にするかも、データに選ばせた（`tools/survey_steering.py`）。
- 神経モデルは Shiu et al. 2024 と同じ LIF とパラメータ。
- 嗅覚（ORN_DM1/DM2/DM4/VM2 と、二酸化炭素の ORN_V）と、触角の機械感覚（Johnston 器官 JO の風と音）も実データ。
  音は巨大繊維 DNp01 に最も強く届く経路で、弱い接近（GF 97 Hz）に空気のふるえが重なると閾値を超える（121 Hz）。
- コネクトームは 1 匹のハエの脳なので左右が完全には対称でなく、回路の一部だけを抜き出すとその偏りが際立つ。
  強い片側だけの投射 17 本にかぎり、鏡像の結合を作って左右をそろえた（`prov: "mirrored"` で区別できる）。
- 感覚 → ニューロン、下行ニューロン → 翅の対応は、作品側が手で決めたもの。

詳しくは [ARCHITECTURE.md](ARCHITECTURE.md)。

## 音楽

Web Audio だけで鳴らす、オリジナルの 7 曲（既存曲の旋律は使っていない）。ステージごとに曲が変わる。
各曲には主題メロディーがあり（曲名から決まる乱数で作曲するので、毎回同じ主題になる）、「主題 → アドリブ → アドリブ → 主題」と進む。
主題を吹く楽器は曲ごとに違い（ホーン・フリューゲル・フルート・シンセ・ビブラフォン・チェレスタ）、
伴奏は FM 合成のエレピとウッドベース、ドラムは起動時に合成して録音した音（ライド・ハット・クラッシュ・キック・スネア・ブラシなど）。
8 小節ごとにフィルとクラッシュが入る。

| 曲 | ノリ |
|---|---|
| Moonlight Swing | ミディアムのスウィング |
| Streetlight Ballad | ブラシのバラード |
| Lunar Bossa | ボサノバ |
| UFO Lounge | 16 ビートのラウンジ |
| Swatter Bop | 速いビバップ |
| Satellite Waltz | ジャズワルツ |
| Witching Hour | 短調の夜想曲（魔女が飛ぶあいだも流れる） |

曲はハエと世界とプレイヤーに反応する：

- 脳の発火が増えるほど、ビブラフォンの即興が増え、音が開き、残響が深くなる
- 旋回ニューロンの左右で旋律が上下し、Giant Fiber で逃げるとシンバルが鳴る
- 高く飛ぶほど旋律の音域が上がり、月に近づくと弦のパッドが満ちていく
- 罠や敵が近いと、パッドに半音の濁りと低い鼓動が混ざる
- カーソルを動かすとキラキラした音が降り、ランタンを灯すと高い和音がふるえる
