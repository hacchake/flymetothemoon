# FLY ME TO THE MOON

FlyWire の配線を素材にした小さな脳が、暗い宇宙のような 2D の世界で光を見て歩く。

人間には、ハエが月を目指しているように見える。
でも、このハエの中に「月」はない。あるのは光と、神経の発火と、脚の動きだけ。

## 遊ぶ

`index.html` をブラウザで開く（ダブルクリックでよい）。インストールも GPU も要らない。

| 操作 | |
|---|---|
| `1` 光 | マウスの位置に光を灯す。ハエは近い光に引き寄せられる |
| `2` 月 | ドラッグで月を動かす |
| `3` 餌 | クリックで置く。空腹のハエは匂いをたどる |
| `4` 岩 | クリックで置く。迫る岩を見ると避ける・跳ぶ |
| 右クリック | 近くの餌・岩を消す |
| `Space` / `R` / `B` / `V` / `D` | 一時停止 / やり直す / 脳の表示 / 視線の表示 / 性能の表示 |

スコアは、月に近づくと加点、月に届くと +500、餌で +50、岩にぶつかると −25。
エネルギーは時間とともに減り、餌で戻る。尽きると次の試行になる。

`tests.html` を開くと、回路の一部を切ったときに行動が崩れるか（損傷テスト）を確かめられる。

## 仕組み

```
光・匂い・迫る岩 → 感覚ニューロン → 小さな LIF 回路 → 下行ニューロン（DNa02, DNp09, MDN, GF…）→ 左右の脚 → 世界が変わる → …
```

詳しくは [ARCHITECTURE.md](ARCHITECTURE.md)。
今の回路（Phase 2）は、**FlyWire の細胞型名と Shiu et al. 2024 の LIF パラメータを使った模式の配線**。
FlyWire の実際の結合データはまだ含まれていない（Phase 3 で取り込む予定）。

## FlyWire のデータとライセンス（重要）

- FlyWire の connectome と注釈データは **CC BY-NC 4.0（表示 — 非営利）** で公開されている。
  取り込む前に、FlyWire Codex（https://codex.flywire.ai）の利用条件で最新の条件を確認すること。
- **非営利**：展示・公開・改変は、出典を示せば可能。
- **商用利用は不可**：作品の販売、有料の展示や入場料、広告・スポンサーの付いた公開、商品への組み込みなどは、
  「商用」に当たるおそれがある。その予定があるなら、**事前に FlyWire チームへ問い合わせる**こと。
- FlyWire のデータから作ったファイル（抽出した回路、`src/circuit_flywire.js` など）も同じ条件を引き継ぐ。
  このリポジトリのコードとは別のライセンスとして扱い、`data/` は配布しない。
- 表示（クレジット）の例：
  > Connectome data: FlyWire Consortium (Dorkenwald et al. 2024, *Nature*; Schlegel et al. 2024, *Nature*), FAFB v783, CC BY-NC 4.0.
  > Neuron model parameters: Shiu et al. 2024, *Nature*.
- 現時点（Phase 2）のコードに FlyWire のデータそのものは入っていない。細胞型の名前と、論文に書かれた性質を参考にしているだけ。
- 参考にした実装のライセンス：Shiu et al. のモデル（MIT）。GPL の実装（`eonsystemspbc/fly-brain`）のコードは取り込まない。

## 構成

依存なしの HTML + JavaScript（Canvas 2D）。ビルド不要で、静的ファイルとしてそのまま公開できる。
Python は、Phase 3 で FlyWire データから回路を抽出するときだけ使う。
